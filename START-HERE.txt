CLAUDIA CARPANESE WEBSITE

1. Extract this ZIP on your computer.
2. Open index.html to preview the site in your browser.
3. In your GitHub repository, choose Add file > Upload files.
4. Upload index.html, research.html, talks.html, style.css and favicon.svg directly into the repository, not inside an extra folder.
5. Click Commit changes.
6. In Settings > Pages, choose Deploy from a branch, main, /(root), then Save.

EDITING
Open a page file on GitHub and click the pencil icon. Edit the words between HTML tags, then Commit changes. Preserve the tags.

PHOTO
Upload a file called portrait.jpg. In index.html, insert this where you want the photo:
<img src="portrait.jpg" alt="Claudia Carpanese" style="width:240px;max-width:100%;height:auto">

CV
Upload your public CV as cv.pdf. In the footer of each page, insert:
<a href="cv.pdf" download>Download my CV</a>

CONTACT
Add your preferred public email in each footer:
<a href="mailto:YOUR-EMAIL">Contact</a>
